# Physical-device acceptance still required

Use a dedicated authorised test directory and the normal Mac account’s Remote Login service. Never rotate the real Mac’s host keys for testing. The independent OpenSSH fixture covers changed trust without doing that.

1. In Xcode choose your signing team, run on an iPhone with iOS 27, and add the dedicated app key’s public key to the Mac account.
2. Enable existing Tailscale on both devices. On iPhone disable Wi-Fi and use cellular. Open a saved favourite directly, verify the host fingerprint, browse, and open a real agent Markdown report.
3. Scroll the folder first; open/back from a report and confirm the folder position. Change the report in the approved Mac test directory, refresh in the reader, and confirm new content. Interrupt the network during another refresh and confirm the previous copy remains clearly labelled.
4. Background/foreground SSH teardown and fresh document read passed on hardware ([evidence](DEVICE_PERMISSIONS_LIFECYCLE.md)). Still verify encrypted-key unlock, cancel/swipe-dismiss, no passphrase persistence, and keychain availability after locking/unlocking the device. Trust a fixture, deliberately change only that fixture's server key, and confirm the connection is blocked before account authentication.
5. Local Wi-Fi denial, useful failure state, Settings recovery, and retry passed on hardware ([evidence](DEVICE_PERMISSIONS_LIFECYCLE.md)). A timeout must not be described as a proven Tailscale/sleep/firewall diagnosis.
6. Check light/dark appearance, accessibility Dynamic Type, VoiceOver reading/focus, Reduce Motion and Reduce Transparency. Long-press to select/copy rendered text and source. Pan a wide code block/table horizontally without widening the overall document.
7. Profile a 1,000-entry folder and the generated 191,002-byte report on the device using Instruments SwiftUI / Animation Hitches. Record cold/warm timings, main-thread hitches and memory; do not interpret Simulator/loopback times as cellular performance.
8. In the authorised test directory, choose **Contents** and search a phrase inside a UTF-8 file whose name does not contain it. Check the source-line snippet, open/back retention, refresh after editing that file, hidden-file policy, cancellation on background/disconnect, and the partial-results explanation at a read limit. On iPad, verify the folder's search controls and snippets with the reader beside them, in a narrow window, with accessibility text sizes and VoiceOver. This content-search journey has not yet been verified on physical hardware.

9. Save an individual file with **Keep Offline**, disconnect, relaunch and open it from **Offline Files** without network access. Verify its saved date, text/media controls and Share Original bytes. Update an authorized fixture, choose **Update Offline Copy**, and interrupt a later update: the last committed copy must remain readable. Remove only the local copy and verify the server original remains. Check Complete file protection while locked using a controlled device test; simulator permissions are not proof. Repeat the library flow in iPad regular and compact windows and with VoiceOver. Offline pinning has not yet received physical-device acceptance.
10. Choose **Keep Folder Offline** for a small controlled tree containing nested and empty directories, hidden files and symbolic links. Check the hidden-file choice and skipped-link count. Disconnect and browse the complete saved hierarchy; preview/share an original, background and relaunch. Change/add/delete remote members and choose **Update Offline Folder**; the replacement must include those changes. Interrupt an update or make a member unreadable and verify the old snapshot remains complete. Remove a saved folder while another window updates it and confirm it never reappears; independently saved files and overlapping snapshots must remain. Exercise a storage/depth limit and verify no partial folder is published.
11. While disconnected, follow relative Markdown links between saved sibling, nested and parent documents, plus same-document and linked heading fragments. Back must retain the source reading position. A missing/hidden/skipped target, unsupported type, query or path leaving the snapshot must explain the failure and retain the reader. Overlapping snapshots and individually saved copies must not substitute for folder members. Repeat between individual copies from the same saved connection route; other accounts/routes must not match. Update/remove an open source in another window and verify its file links require reopening. No file-link tap should reconnect or download missing content.

12. In a long standalone HTML fixture, scroll into prose and a tall visual/table block, then rotate the iPhone, change text size and resize an iPad window. Reopening the unchanged file and switching Rendered/Source must retain their independent locations; changed content starts at the top. Interrupt restoration with touch, keyboard and VoiceOver scrolling, then background/foreground and navigate Back. Confirm document scripts/resources remain blocked and profile inactive HTML reader memory. These HTML anchor checks still need physical-device acceptance.

The app has no background modes and makes no promise of keeping SSH open while suspended. Complete this journey before describing the preview as physically verified.
